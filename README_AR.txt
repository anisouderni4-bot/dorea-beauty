D’ORÉA BEAUTY — نسخة أولية للنشر على Render

ماذا تحتوي:
- متجر للزبائن مع سلة وطلبية بالدفع عند الاستلام.
- لوحة Admin محمية بكلمة مرور.
- إضافة/تعديل/حذف المنتجات.
- متابعة الطلبات وتغيير حالتها.
- PostgreSQL لحفظ المنتجات والطلبات على الإنترنت.

قبل النشر:
1) ارفع محتويات هذا المجلد إلى GitHub في مستودع جديد.
2) في Render أنشئ Web Service من المستودع.
3) Build Command: npm install
4) Start Command: npm start
5) أضف متغيرات البيئة:
   DATABASE_URL = رابط Internal Database URL من PostgreSQL على Render
   ADMIN_PASSWORD = كلمة مرور قوية تختارها
   JWT_SECRET = سلسلة عشوائية طويلة وسرية
6) أنشئ PostgreSQL في نفس المنطقة، ثم اربط DATABASE_URL.
7) بعد النشر افتح رابط الموقع، وانزل إلى Espace Admin وسجّل بكلمة المرور ADMIN_PASSWORD.

مهم:
- لا تضع كلمات المرور داخل ملفات الكود أو GitHub.
- هذه نسخة تأسيسية: صور المنتجات تُضاف كرابط صورة مباشر (URL)، وليست رفع ملفات من الجهاز بعد.
- لا توجد بوابة دفع إلكتروني حالياً؛ الطلبات بالدفع عند الاستلام.
- اختبر طلبية تجريبية قبل الإعلان عن الموقع.
